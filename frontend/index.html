Dataset

Images were read from three class folders (COVID2_CT, pneumonia_CT, Normal_CT). 70% / 30% train–test split, stratified by class, random_state 42.

Image Preprocessing

Each image is read with OpenCV, converted from BGR to RGB, resized to 224×224 pixels, then normalized with DenseNet's preprocess_input.

Feature Extraction

DenseNet121 with ImageNet weights, without its classification layer and with all layers frozen, acts as a fixed feature extractor. Its 7×7×1024 output is flattened into a 50,176-value vector for each image.

Read these scores with caution

Scores are near perfect, which can indicate leakage: the split is random by image, so slices from one patient may appear in both train and test. There is one split with no cross-validation, and one dataset. The models always choose one of three classes, even for an image that is not a chest CT.

About

Project Objective

This project explores how well features from a pretrained image network, combined with classical machine-learning classifiers, can separate chest CT scans into COVID-19, Pneumonia and Normal classes.

Machine Learning Approach

CT images are resized and normalized, passed once through a frozen DenseNet121 to produce feature vectors, and then classified by SVM, Random Forest and Logistic Regression. The three results are compared.
